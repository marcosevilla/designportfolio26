## 4. Performance — PASS

Measured by patching `WebGL2RenderingContext.prototype.drawArrays` / `drawElements` and
attributing each call to `this.canvas`. **No canvas was ever removed from the DOM** (the known
trap — the draw closure holds the ref and keeps rendering into a detached bitmap).

Homepage carries **8** dither canvases (2036×1660 drawing buffer each) + 1 PixelRain 2D canvas
+ 1 LedMatrix.

### Dither viewport gating (F-11)

| Condition | Total GL draws / 3s | Per-canvas |
|---|---|---|
| Page top, marquee `scrollLeft: 0` | **360** | `1:180  2:180`, six others **0** |
| Marquee `scrollLeft: 2200` | **543** | `4:181  5:181  6:181`, five others **0** |
| Page `y: 3000` (marquee off-screen) | **0** | all **0** |

180 draws / 3s = 60fps. Only the on-screen canvases run; the gate follows both scroll axes and
an off-screen marquee parks everything. Consistent with the claimed −75%.

### The blank-card risk — investigated hard, and it's clear

This was the failure mode worth hunting: `inView` starts `false`, so a card that has never been
scrolled into view has never drawn, and a blank card would be worse than the perf problem.

- Cold load, before any scroll: canvases 3–8 sit at **0 draws** — genuinely blank buffers.
- The library saves this: `shader-mount.js:178` and `:332` call `render()` once on resize and on
  uniform change even at `speed=0`. Measured — on the first marquee scroll, all six parked
  canvases drew **exactly 1 frame at +25ms**, then held (3,4,5,6 stayed at exactly 1 draw while
  7,8 ran on to 121). So a parked card always holds a real frame.
- **Decisive test:** realistic gradual wheel scroll across the whole strip, sampling every rAF
  whether any canvas was *visible in the viewport but had never drawn*. Over **251 frames**:
  **1 violation** — canvas 2, **95px** of it visible, for a **single 16ms frame**. Sub-perceptual.
  All 8 canvases ended drawn.

### Visual confirmation, both themes

Element screenshots of `.work-marquee` at `scrollLeft` 0 / 1088 / 2176 / 3652 in light and dark
(8 captures) plus a cold-jump capture. **All 8 backdrops render their halftone art correctly in
both themes.** Where a card shows plain fill in one corner that is the seeded
`offsetX/offsetY/scale` variation (documented art-direction contract), not a blank canvas —
