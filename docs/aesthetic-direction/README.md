## The one thing to remember

Most retro-computing sites simulate a **screen** (scanlines, cursor, phosphor green) — that's a costume. This direction simulates a **document**: the computing lives in the information architecture (numbered sections, spec tables, figure plates, revision blocks) and the typography stays properly editorial (real text serif, real measure). That split is the whole competitive advantage, and it's how this goes past makingsoftware.com rather than copying it.
